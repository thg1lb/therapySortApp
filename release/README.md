# How to run TherapySort

## 1. Ensure `backend.exe` and `therapySort.db` are in the same folder
If they are not in the same location, the Flask API will not be able to access the therapists table within the database.

## 2. Open `backend.exe` and ensure the server is hosted locally
It will be stated via the terminal whether the server is live on http://127.0.0.1:5000. If further verification is needed this link can be followed into a local browser where a confirmation message should be displayed.

## 3. Extract the Unity zip file `TherapySort.zip`
This folder does not need to be extracted in the same location as the backend for the application to work, however all the contents of the folder must remain in the same location.

## 4. Open `TherapySortApp.exe`
As long as the `.zip` folder was extracted altogether, there should be no errors upon opening the application.

## 5. Enjoy!
The application should be functional. One thing to note is that the app does not contain an exit button, please resort to `Alt + F4` for this or the `Windows Key`  to close it from the task bar. Thank you!
